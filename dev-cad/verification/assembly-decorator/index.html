Imported @assembly subassembly

What this example makes

Two identical 10 x 10 x 20 mm posts remain at X=-15 and X=+15 while the imported @assembly result builds from a replay-safe component/copy command plan.

Forge code

This is the complete Forge source used for this example.

"""Qualification: an imported @assembly compiles as a native subassembly."""

from subassembly import PostPair


class ImportedAssembly:
    def build(self):
        return PostPair()


ImportedAssembly()

API used

@component class Post; @assembly class PostPair; root model imports and returns PostPair()

import cadquery as cq


post = cq.Solid.makeBox(
    10,

    cq.Vector(-5, -5, 0),

model = cq.Assembly()

model.add(post, name="right", loc=cq.Location((15, 0, 0)))

"""build123d reference: two posts built from one reusable shape."""
from build123d import Align, Box, BuildPart, Locations

bottom = (Align.CENTER, Align.CENTER, Align.MIN)

with BuildPart() as model:
    with Locations((-15, 0, 0), (15, 0, 0)):
        Box(10, 10, 20, align=bottom)
