Rounded Sketch pad and standalone world-plane cut

Attached and standalone Sketch extrusions remain native editable features

A named face-attached RoundedRectangle2D joins a pad to the base, then a second standalone YZ Sketch cuts an internal tunnel through the body with a symmetric native extrusion.

80 × 60 × 5 mm base; 40 × 30 × 8 mm rounded pad; 10 × 2 mm world-plane cut; 100 mm symmetric cut extrusion22 generated SolidCraft commands

Model stages

  1. Create the native Box base
  2. Create and join the TOP-face rounded-rectangle Sketch
  3. Create an independent YZ world-plane Sketch
  4. Cut that standalone Sketch through the existing body with one native symmetric extrusion

Goal

Qualify RoundedRectangle2D in the explicit named Sketch API using true native rounded-rectangle sketch geometry.

Forge API

with Sketch(name='Rounded pad', on=body): add(RoundedRectangle2D(...)); body + sketch.extrude(...)

Forge model

One 80 x 60 x 5 mm base plate plus a centered 40 x 30 mm rounded-rectangle pad with 5 mm corner radius and 8 mm height.

How Forge builds it in SolidCraft

The named explicit Sketch emits one sketch.rectangle.rounded with true arc corners, then a native solid.extrude(operation='join').

SolidCraft result

The result is one joined body: an 80 x 60 x 5 mm base plate with a centered 40 x 30 x 8 mm rounded pad on top. The Rounded pad sketch has one closed profile made from four straight edges and four corner arcs. SolidCraft 0.42 also adds one construction diagonal between opposite arc centres; that construction line is not part of the profile.

Saved-design test

No saved-design mutation in this fixture; it isolates explicit rounded-rectangle sketch geometry and native join extrusion.

Geometry evidence

Reference notes

  • SolidCraft — Native rounded sketch rectangles preserve true arc geometry and remain inspectable in the saved sketch.
  • PythonSCAD — The explicit Sketch scope keeps 2D profile authoring separate from the subsequent 3D extrusion.

Python source

"""Qualification: attached rounded pad plus standalone world-plane cut."""


class RoundedRectangleSketch:
    base_width = 80.0
    base_depth = 60.0
    base_height = 5.0
    pad_width = 40.0
    pad_depth = 30.0
    radius = 5.0
    pad_height = 8.0
    cut_width = 10.0
    cut_height = 2.0
    cut_y = 22.0
    cut_z = 2.5
    cut_length = 100.0

    def build(self):
        body = Box(
            self.base_width,
            self.base_depth,
            self.base_height,
            anchor=Anchor.BOTTOM,
        )

        with Sketch(name="Rounded pad", on=body) as pad:
            pad.add(
                RoundedRectangle2D(
                    self.pad_width,
                    self.pad_depth,
                    self.radius,
                ),
            )

        body = body + pad.extrude(self.pad_height)

        with Sketch(name="World cut", plane="YZ") as cut:
            cut.add(
                Rectangle2D(self.cut_width, self.cut_height),
                offset=(self.cut_y, self.cut_z),
            )

        return body - cut.extrude(self.cut_length, sym=True)
