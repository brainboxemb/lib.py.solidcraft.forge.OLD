Native sketch Slot family

SolidCraft 0.45 native Slots keep width, straight length and position editable

One plate sketch contains all five native Slot construction methods. The three straight Slots use editable axis-aligned authored endpoints, all five share one editable native width parameter, and one through cut removes the complete family.

160 × 120 × 5 mm plate; baseline 8 mm Slot width; editable straight-Slot length and Y position30 generated SolidCraft commands

Model stages

  1. Create the native Box plate
  2. Create three straight native Slots from editable axis-aligned endpoint parameters
  3. Create two arc Slots from fixed authored points
  4. Drive all five Slot widths from one editable native width parameter
  5. Cut the complete Slot family through the plate once
  6. Mutate width, straight length and straight position in the saved SolidCraft design

Goal

Qualify all five SolidCraft 0.45 Slot construction methods as direct Forge sketch profiles, and prove the native parametric contracts that Forge exposes. The three straight Slot variants keep axis-aligned length and position editable. All five Slot variants keep width editable. Forge must not approximate any Slot with rounded rectangles or hand-built curves.

Forge API

```python SlotCenterToCenter2D(...) SlotOverall2D(...) SlotCenterPoint2D(...) SlotArcThreePoint2D(...) SlotArcCenter2D(...) ``` inside one explicit `Sketch`.

Forge model

One 160 × 120 × 5 mm plate contains five Slot profiles in one named sketch. Baseline geometry intentionally matches the historical qualification: - width: 8 mm; - straight-Slot Y: -35 mm; - centre-to-centre Slot centres: X=-60 .. -40; - overall Slot endpoints: X=-10 .. 20; - centre-point Slot: centre X=55, end-centre X=65; - both arc Slot paths retain fixed authored points. The lower-case straight-Slot coordinates and `slot_width` are normal editable Forge model parameters.

How Forge builds it in SolidCraft

Fixed authored Slot points still use the direct native `sketch.slot.*` creator. For the three straight Slots, symbolic authored endpoints are evaluated only for numeric seed geometry. Forge then uses native `sketch.draw.dimensioned` with the SolidCraft 0.45 `length` role, constrains the returned native `centre_line` horizontal/vertical and dimensions the returned native `middle` point from the sketch origin. The direct Slot point fields therefore remain numeric while native SolidCraft dimensions retain the editable length and position expressions. The two arc Slots keep fixed authored points but share the same editable native width expression.

SolidCraft result

SolidCraft saves: - one plate body; - one solved `Slot family` sketch with five closed native Slot profiles; - one error-free through-cut extrusion. The native timeline must not contain `sketch.rectangle.rounded` as a Slot substitute.

Saved-design test

Without rerunning Forge Python, change the saved SolidCraft parameters: - `slot_width`: 8 -> 10 mm; - `straight_y`: -35 -> -20 mm; - centre-to-centre end X: -40 -> -35 mm; - overall end X: 20 -> 25 mm; - centre-point end X: 65 -> 70 mm. The saved design must rebuild solved native Slot geometry with the new width, straight lengths and position. The body envelope stays the same while the through-cut volume changes deterministically.

Geometry evidence

Are outer bounds sufficient? no

The five Slot cuts do not change the plate envelope. Baseline volume and 3D slot-wall probes remain required. The saved-design mutation additionally checks the mutated parameter values, solved sketch state and resulting body volume.

Python source

"""Qualification fixture for SolidCraft 0.45 native parametric Slots."""


class SlotFamily:
    width = 160.0
    depth = 120.0
    thickness = 5.0

    slot_width = 8.0
    straight_y = -35.0

    c2c_start_x = -60.0
    c2c_end_x = -40.0

    overall_start_x = -10.0
    overall_end_x = 20.0

    center_point_x = 55.0
    center_point_end_x = 65.0

    def build(self):
        body = Box(
            self.width,
            self.depth,
            self.thickness,
            anchor=Anchor.BOTTOM,
        )

        with Sketch(name="Slot family", on=body) as slots:
            SlotCenterToCenter2D(
                (self.c2c_start_x, self.straight_y),
                (self.c2c_end_x, self.straight_y),
                self.slot_width,
            )
            SlotOverall2D(
                (self.overall_start_x, self.straight_y),
                (self.overall_end_x, self.straight_y),
                self.slot_width,
            )
            SlotCenterPoint2D(
                (self.center_point_x, self.straight_y),
                (self.center_point_end_x, self.straight_y),
                self.slot_width,
            )
            SlotArcThreePoint2D(
                (-50, 25),
                (-35, 38),
                (-20, 25),
                self.slot_width,
            )
            SlotArcCenter2D(
                (40, 25),
                (52, 25),
                self.slot_width,
                sweep=120,
            )

        return body - slots.extrude(Depth.THROUGH_ALL)
