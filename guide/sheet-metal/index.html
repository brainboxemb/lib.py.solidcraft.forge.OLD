API Guide / Sheet metal

Sheet metal

Native sheet rules, folds, flanges, hems, paths and recoverable flat patterns.

Sheet metal is native editable history

Forge sheet-metal operations lower to SolidCraft sheet rules and native sheet features. Use them when the saved design must keep material thickness, bend allowance and a recoverable flat pattern. Do not replace these operations with fused solid envelopes when native history matters.

One sheet rule owns the material

A sheet body has one active rule. That rule owns thickness, k_factor and the default bend_radius. Operations on an existing sheet inherit those values instead of restating them. Feature-specific dimensions such as flange height, hem length or a path-flange radius override remain on the feature.

Create a flat sheet body

with Sketch(name="Blank", plane="XY") as sketch:
    Rectangle2D(80, 40)

sheet = sketch.sheet_metal(
    thickness=2,
    bend_radius=2,
    k_factor=0.5,
    rule_name="Panel sheet",
)

Sketch.sheet_metal() creates a new sheet body from one closed Sketch. It is a body-creation operation, not a feature applied to an existing sheet.

Fold existing material

sheet = sheet.fold(
    line=((20, -20, 0), (20, 20, 0)),
    angle=90,
    fixed=(-30, 0, 0),
)

Shape.fold() bends material that already belongs to the sheet. The initial contract uses one straight fixed-coordinate fold line. Thickness, K-factor and bend radius come from the active rule.

Grow an edge flange

sheet = sheet.flange(
    edges=[(40, 0, 2)],
    height=20,
    angle=90,
)

Shape.flange() adds material to explicit existing sheet edges. Height and angle may remain parameterized. Edge selection is currently a non-empty set of fixed XYZ pick points; generic topology selectors are not yet part of this API.

Create a sheet from an open contour

with Sketch(name="Contour", plane="XZ") as sketch:
    chain = sketch.chain(start=(0, 0))
    chain.line_to((35, 0))
    chain.tangent_arc_to((40, 5))
    chain.line_to((40, 30))
    contour = chain.finish()

sheet = contour.contour_flange(
    distance=50,
    thickness=2.5,
    bend_radius=2.5,
    k_factor=0.44,
)

Shape.contour_flange() is the other body-creation operation. Its receiver is a finished connected open Sketch chain. Forge preserves chain order and replay-bound native curve identity; callers do not pass SolidCraft curve ids.

Hem an existing edge

sheet = sheet.hem(
    edges=[(40, 0, 2)],
    length=12,
    gap=4,
)

Shape.hem() folds an existing edge back onto the sheet while inheriting the active material rule. The first contract uses fixed XYZ edge picks. Length and optional gap are feature dimensions and may be parameterized.

Follow a reusable path

with Sketch(name="Path", plane="XZ") as sketch:
    chain = sketch.chain(start=(0, 0))
    chain.line_to((0, 14))
    path = chain.finish()

sheet = sheet.path_flange(
    edge=(40, 0, 2),
    path=path,
    radius=3,
)

Shape.path_flange() adds a native flange to an existing edge using a finished open Sketch path. The qualified SolidCraft 0.45 contract is line-only. Omitting radius inherits the active rule; supplying it overrides only this feature's bend radius.

Apply a whole-sheet perforation field

sheet = sheet.perforate(
    diameter=5,
    pitch=10,
    margin=5,
    pattern="square",
)

Shape.perforate() adds native manufacturing perforation semantics to existing sheet material. Diameter and pitch are positive millimetre dimensions. margin is optional; omitting it leaves SolidCraft's native diameter-sized margin default in control. pattern is staggered by default or may be square.

The first Forge contract applies to the whole sheet. It deliberately does not expose SolidCraft's Sketch/profile-bounded region fields. Perforations remain flat-pattern/DXF/measurement semantics rather than repeated B-rep holes.

Editable dimensions versus topology picks

Keep design dimensions symbolic when the method accepts Parameter/Expression values. Current edge picks and straight fold-line coordinates are intentionally fixed finite coordinates. Forge rejects unsupported associative selectors instead of pretending a numeric pick is a stable topology reference.

Verification and flat patterns

Native sheet-metal verification is stronger than matching a formed bounding box. Verification cases inspect sheet-rule values, native bend/history records, saved-design parameter edits and the recoverable flat pattern. See the Verification catalog, especially the Sheet metal group.

API on this page

These values and signatures are generated from the current Python API. They are shown here so the normal guide flow does not require opening the reference for every detail.

Shape.fold()

Fold existing sheet material along one straight line.

Shape.fold(self, *, line, angle=90, fixed=None, position='centerline', flip=False)

Use when: Bend material that already exists in a sheet blank. Dimensions and bend allowance come from the sheet's shared rule.

Current limits: This first qualified form supports one straight fold line. The line endpoints and fixed point are fixed finite coordinates.

Shape.flange()

Add a native edge flange to existing sheet material.

Shape.flange(self, *, edges, height, angle=90, height_from=None, position=None, flip=False)

Use when: Grow new sheet material from one or more existing sheet edges while inheriting thickness, K-factor and bend radius from the sheet rule.

Current limits: This first slice accepts explicit fixed XYZ edge pick points only. Per-edge segment dictionaries, corner relief overrides, chained bends and radius overrides are intentionally not exposed.

Shape.contour_flange()

Create a native contour-flange sheet from an open Sketch chain. The receiver must be the Shape returned by Sketch.chain(...).finish(). Material dimensions define the sheet rule used by the new body; the contour feature itself receives only that rule name.

Shape.contour_flange(self, *, distance, thickness, bend_radius, k_factor=0.5, rule_name='Forge Sheet', flip=False, reverse=False)

Shape.hem()

Add a native hem to existing sheet material.

Shape.hem(self, *, edges, length, gap=None, flip=False)

Use when: Fold one or more existing sheet edges back on the sheet while preserving native sheet-metal history and the inherited rule.

Current limits: This first slice accepts explicit fixed XYZ edge pick points only. Generic edge selectors and compound hem profiles are intentionally outside this contract.

Shape.path_flange()

Add a native path flange to existing sheet material.

Shape.path_flange(self, *, edge, path, radius=None)

Use when: Create a multi-leg native flange from an existing sheet edge using one reusable open Sketch path.

Current limits: The initial SolidCraft 0.45 contract accepts line-only open chains. Tangent arcs and generic edge selectors are intentionally rejected until the native path-flange runtime proves those contracts.

Shape.perforate()

Add a native whole-sheet perforation field.

Shape.perforate(self, *, diameter, pitch, margin=None, pattern='staggered')

Use when: Describe manufacturing perforations that belong to sheet flat-pattern, DXF and measured-volume semantics without cutting repeated B-rep holes.

Current limits: This first slice covers the whole sheet only. Sketch/profile-bounded local perforation regions are intentionally outside the contract.

Sketch.sheet_metal()

Create a native sheet-metal body from this closed flat Sketch.

Sketch.sheet_metal(self, *, thickness, bend_radius, k_factor=0.5, rule_name='Forge Sheet')

Use when: Start a fabricated sheet part from its flat blank before applying holes, folds, hems or other sheet-metal features.

Current limits: The first qualified form requires one standalone XY Sketch with one closed profile. Leave the Sketch scope before creating the sheet.
