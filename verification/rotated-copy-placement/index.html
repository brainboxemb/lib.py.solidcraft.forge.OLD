Copied Placement with rotation

What this example makes

Two rotated 10 x 20 x 4 mm envelopes remain centred at X=-40 and X=+40. No placement joint is created.

Forge code

This is the complete Forge source used for this example.

"""Qualification: copied Placement keeps translation when rotation is present."""


class Panel:
    def build(self):
        return Box(20, 10, 4)


class RotatedCopyPlacement:
    def build(self):
        left = Panel(
            placement=Placement(
                x=-40,
                rotation=(Z, 90),
            )
        )
        right = left.copy(
            placement=Placement(
                x=40,
                rotation=(Z, 90),
            )
        )
        return left + right


RotatedCopyPlacement()

API used

"""CadQuery reference for two independently placed rotated panel occurrences."""

import cadquery as cq

# The Forge definition is 20 x 10 x 4 and each occurrence is rotated Z+90,
# giving a centred 10 x 20 x 4 world envelope.
panel = cq.Solid.makeBox(
    20,
    10,
    4,
    cq.Vector(-10, -5, -2),
)
rotation = cq.Location(cq.Vector(0, 0, 0), cq.Vector(0, 0, 1), 90)

model = cq.Assembly()
model.add(panel, name="left", loc=cq.Location((-40, 0, 0)) * rotation)
model.add(panel, name="right", loc=cq.Location((40, 0, 0)) * rotation)

"""build123d reference: two translated and Z-rotated panel occurrences."""
from build123d import Align, Box, BuildPart, Locations, Rot

center = (Align.CENTER, Align.CENTER, Align.CENTER)

with BuildPart() as model:
    for x in (-40, 40):
        with Locations((x, 0, 0)):
            with Locations(Rot(0, 0, 90)):
                Box(20, 10, 4, align=center)

How Forge builds it in SolidCraft

Forge creates/copies the Panel occurrence at native identity, binds each real occurrence ID, then applies each complete translation and Z=90 degree orientation through occurrence.move. No predicted Component:N name and no pre-rotated copy translation is used.
